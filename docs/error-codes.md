# Коды ошибок NORA VPN

Код помогает быстро понять, к какому разделу относится проблема.

| Код | Что означает | Что сделать |
|---|---|---|
| `VPN-001` | Android не выдал разрешение VPN | Повторите подключение и подтвердите системный запрос |
| `IMPORT-001` | Профиль не удалось импортировать | Проверьте, что ключ, ссылка или файл скопированы полностью |
| `IMPORT-002` | Формат не поддерживается | Используйте один из форматов из README |
| `BACKEND-001` | Переключение подключения еще выполняется | Подождите несколько секунд и повторите действие |
| `BACKEND-002` | Переключение заняло слишком много времени | Отключите VPN и подключитесь снова |
| `BACKEND-003` | Не удалось подготовить подключение | Повторите подключение или выберите другой сервер |
| `XRAY-101` | Не удалось запустить Xray | Проверьте профиль и доступность сервера |
| `XRAY-102` | Не удалось корректно остановить Xray | Повторите отключение или перезапустите приложение |
| `AWG-101` | Не удалось запустить AmneziaWG | Проверьте конфигурацию и доступность сервера |
| `AWG-102` | Не удалось корректно остановить AmneziaWG | Повторите отключение или перезапустите приложение |
| `KROT-101` | Не удалось подключиться по KRot | Проверьте ключ и доступность сервера |
| `KROT-102` | Не удалось корректно остановить KRot | Повторите отключение или перезапустите приложение |
| `SOCKS-001` | Указан неверный порт SOCKS | Введите порт от 1 до 65535 |
| `SOCKS-002` | Не заполнены данные SOCKS | Создайте новые данные в настройках SOCKS |
| `SPLIT-001` | Не выбраны приложения | Добавьте хотя бы одно приложение в раздельное туннелирование |
| `SPLIT-002` | Настройки туннелирования не применились | Повторите сохранение настроек |
| `NOTIFY-001` | Нет разрешения на уведомления | Разрешите уведомления в настройках Android |
| `TILE-001` | Плитке требуется разрешение VPN | Один раз подключитесь из приложения |
| `TILE-002` | Плитка не смогла изменить состояние VPN | Откройте приложение и повторите действие |
| `SUBS-001` | Подписку не удалось добавить | Проверьте URL |
| `SUBS-002` | Подписку не удалось обновить | Проверьте интернет и повторите обновление |
| `SUBS-003` | Импортирована только часть серверов | Откройте сведения подписки или обновите ее позже |
| `SUBS-004` | Не удалось изменить подписку | Повторите действие |
| `UI-001` | Действие не выполнено | Повторите действие |
| `UI-002` | Экран находится в неподходящем состоянии | Вернитесь назад и откройте раздел снова |

Если ошибка повторяется, приложите к обращению код ошибки и краткое описание действий. Не публикуйте ключи, конфигурации и ссылки подписок.
