# Обзор NORA VPN

NORA VPN — Android-приложение для управления VPN-подключениями, прямыми профилями и подписками.

## Основные разделы

- **Главная** — состояние подключения, активный сервер и быстрая смена сервера.
- **Серверы** — подписки, прямые профили, обновление и замер задержки.
- **Добавить** — импорт ключа, ссылки, подписки или файла конфигурации.
- **Трафик** — текущая скорость, объем VPN-трафика и история сессий.
- **Настройки** — раздельное туннелирование, логи, DNS, уведомления и дополнительные параметры.

## Подключения

Приложение поддерживает:

- KRot;
- Xray / VLESS / REALITY;
- AmneziaWG 2.0.

Выбранный тип профиля запускается своим контуром подключения. Переключение сервера выполняется из общего списка и не изменяет остальные сохраненные профили.

## Профили и подписки

Прямые профили и серверы из подписок отображаются в одном разделе. Подписки можно раскрывать, обновлять и настраивать отдельно. Активный сервер выделяется и открывается автоматически при переходе с главного экрана.

## Раздельное туннелирование

Режим позволяет выбрать приложения, которые должны использовать VPN. Трафик остальных приложений не включается в статистику VPN-сессии.

## Данные приложения

Профили, подписки, настройки и история сессий хранятся локально на устройстве. NORA VPN не публикует их и не использует реальные пользовательские данные в демонстрационных материалах репозитория.
