# Безопасность

## Ключи и профили

- Не публикуйте ключи `nora1.`, VPN-конфигурации и ссылки подписок.
- Не отправляйте посторонним файлы профилей и скриншоты с открытыми адресами.
- Добавляйте профили только из источников, которым доверяете.

## Установка

- Загружайте APK из официального репозитория NORA VPN.
- Не устанавливайте сборки из неизвестных источников.
- Проверяйте запрашиваемые Android разрешения.

## Раздельное туннелирование

Проверяйте список выбранных приложений после установки новых программ или изменения настроек.

## Публичные отчеты

При создании issue указывайте версию Android, модель устройства и код ошибки. Перед публикацией скройте ключи, адреса серверов, ссылки подписок и другие личные данные.
