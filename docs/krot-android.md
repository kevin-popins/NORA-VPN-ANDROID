# KRot на Android

NORA VPN поддерживает подключение по протоколу **KRot**.

## Добавление профиля

1. Откройте раздел добавления через кнопку `+`.
2. Выберите формат **KRot key**.
3. Вставьте ключ, начинающийся с `nora1.`.
4. Нажмите **Добавить в NORA VPN**.
5. Выберите появившийся сервер и подключитесь.

Ключ `nora1.` содержит данные для подключения. Не публикуйте его и не передавайте посторонним.
